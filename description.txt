🚀 Excited to announce my latest project: MiniCursor! 🚀

I've been working on building a fully functional, web-based AI coding assistant inspired by Cursor, right in the browser! It's designed to give you an agentic AI pair programmer that doesn't just chat, but can actually act on your codebase.

✨ **Key Features:**
• **Agentic AI Workflow:** Powered by the Gemini API (gemini-3.1-flash-lite), the assistant can autonomously read, write, and manage files, as well as execute terminal commands!
• **Real-time Synchronization:** Built with WebSockets for seamless, real-time streaming of AI responses and tool executions.
• **Integrated File Explorer & Editor:** A complete IDE-like experience in the browser with an interactive file tree and a beautiful syntax-highlighting code viewer.
• **Premium Glassmorphic UI:** A sleek, mobile-responsive design with dark mode, subtle animations, and a polished user experience.
• **Persistent Sessions:** State and file history are automatically saved, so you never lose your progress!

🛠️ **Tech Stack:**
• **Frontend:** React.js, Vite, Vanilla CSS
• **Backend:** Python, Flask, Flask-SocketIO
• **AI Engine:** Google Gemini API 

Building this full-stack application was an incredible journey, particularly in handling the complexities of stateful web sockets, agent tool-calling, and designing a highly responsive mobile UI!
